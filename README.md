# OZON × CDEK

Полный редизайн cdek-ozon.ru на визуальной основе OZON × DPD. Сохранены исходные условия, тарифы, все 14 FAQ, история, результаты и внешние ссылки. Никакие изменения DPD о бесплатности на CDEK не переносились.

## Запуск

Node.js 22+. `npm ci`, затем `npm run dev`. Сборка: `npm run build`. Предпросмотр сборки: `npm run preview`. Проверка: `npm run check`. Обработчик формы: `python server/test_leads.py`. После сборки HTML содержит всю страницу до запуска JavaScript. Для пререндеринга используется установленный Chrome; путь можно задать через `PW_EXECUTABLE_PATH`.

## Размещение

`node scripts/deploy.cjs` читает доступы из локальных `info/VPS.txt` и `info/Telegram.txt`. На VPS всё приложение расположено в `/var/www/OZON-CDEK`: `site/` — опубликованная сборка и видео; `src/`, `scripts/`, `server/`, `deploy/` — исходники и конфигурация; `data/` — SQLite заявок; `.private/` — секреты и резервная копия конфигурации. Публично доступна только `site/`. Тестовый маршрут `/OZON-CDEK/` исключён из индексации. Исходный домен и DPD сохраняются.

Форма на VPS работает через относительный `./api/leads`; Nginx направляет запрос на локальный порт 4193. Сервер проверяет источник, контакты и тариф, ограничивает запросы, сохраняет заявку в SQLite и отправляет её в Telegram. Успех возвращается после подтверждения Telegram. Повторная попытка с тем же UUID не дублирует успешно доставленную заявку. При переносе на домен следует изменить `LEADS_ORIGIN` в закрытом env, настроить TLS-виртуальный хост и убрать noindex тестового маршрута.

## GitHub Pages

Репозиторий: https://github.com/divangames/ozon-cdek. Сайт: https://divangames.github.io/ozon-cdek/. `npm run deploy:pages` собирает версию с публичным адресом обработчика VPS, выполняет пререндеринг и публикует только dist в gh-pages. Авторизация берётся из Git Credential Manager, токен не сохраняется в проект. Сборка Pages использует `VITE_LEADS_URL`; сервер допускает CORS только с адреса VPS и `https://divangames.github.io`. В открытом репозитории нет info/, приватных оригиналов и данных заявок.

## Материалы

Логотип и favicon предоставлены владельцем. Четыре снимка сделаны в действующем кабинете; ключи, реквизиты аккаунта и контакты закрыты до захвата. Видеоролики из `video/load/` оптимизированы для веб; в двух роликах убрана верхняя панель с аккаунтом. Оригиналы не изменены. Иллюстрации кейсов взяты из соответствующего блока исходного сайта. Источники указаны в `public/images/provenance.json` и `public/tutorials/provenance.json`.

Мониторинг формы: `systemctl status ozon-cdek-leads`; экспорт заявок на сервере: `sudo -u www-data env LEADS_DB=/var/www/OZON-CDEK/data/leads.sqlite3 python3 /var/www/OZON-CDEK/server/leads.py --export`. Экспорт содержит персональные контакты; хранить приватно.
